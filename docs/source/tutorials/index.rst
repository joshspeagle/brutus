Tutorials
=========

Interactive Jupyter notebooks demonstrating the complete brutus workflow,
from data setup through fitting, analysis, and visualization.

.. note::

   These tutorials use real astronomical data and pre-computed results.
   Some tutorials require large model grids to be downloaded first --
   see :doc:`Tutorial 0 <tutorial_00_data_setup>` for setup instructions.
